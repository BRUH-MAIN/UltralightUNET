# UltraLight VM-UNet replication -- Linux, NVIDIA Blackwell (RTX 50-series, sm_120)
#
# Install in three steps; the order matters, because the mamba wheels are chosen
# by reading the installed torch.
#
#   1. torch, from a CUDA 12.9 index:
#        pip install torch==2.10.0 torchvision==0.25.0 \
#            --index-url https://download.pytorch.org/whl/cu129
#
#      Blackwell needs torch >= 2.7 built with CUDA >= 12.8; 2.7.0 was the first
#      stable release shipping sm_120 kernels. 2.10.0 is pinned because the
#      mamba_ssm project publishes prebuilt wheels per torch minor, and 2.10 is
#      the newest it covers -- torch 2.11+ would mean compiling from source.
#
#   2. the two CUDA extensions the paper uses (mamba_ssm, causal_conv1d):
#        python scripts/install_mamba.py
#
#      PyPI has sdists only for these. That script installs the matching
#      prebuilt wheels from the projects' GitHub releases instead; see its
#      docstring for the naming scheme and the Blackwell caveat.
#
#   3. this file:
#        pip install -r requirements.txt
#
# torch/torchvision/mamba_ssm/causal_conv1d are deliberately NOT listed below:
# each needs an index or a URL that a bare requirements line cannot express, and
# listing them here invites a resolver to replace a working CUDA build with a
# CPU one from PyPI.
#
# numpy is left loose (>= 1.26) because modern torch builds ship against numpy
# 2.x. Nothing here is numerically sensitive to it -- numpy only does the dataset
# mean/std and the sklearn confusion matrix; all training arithmetic is torch.
